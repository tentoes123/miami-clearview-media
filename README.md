# Miami Clearview Services — website photos

Public, web-optimized photos for [miamiclearviewservices.com](https://miamiclearviewservices.com).

These are real job photos from the @miamiclearviewservices Instagram grid, resized to a max width of 1600px, saved as JPEG (quality 82), with EXIF removed. The house-number plaque on `home-exterior-cleaning-miami.jpg` was removed before upload.
